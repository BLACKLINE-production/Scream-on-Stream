You can also add screamers straight into OBS/TikTok Studio as a Browser Source — this avoids display-capture issues (like a black screen) some setups run into.

  1. Open OBS → Sources → click +
  2. Select "Browser"
  3. Paste the link to the overlay (located below)
  4. Set Width/Height to match your canvas resolution (e.g. 1920×1080)
  5. Drag it to the very top of your Sources list, above your game/webcam
  1. Open TikTok Live Studio → top-left square → click "Add Source"
  2. Select "Link" → Add
  3. Paste the link to the overlay (located below)
  4. Set Width/Height to match your canvas resolution (e.g. 1920×1080)
  5. Drag it to the very top of your Sources list, above your game/webcam
Link to add the screamer overlay

If "Screen Capture" is selected as the display source, we recommend not connecting the overlay and leaving the "Screen Capture" source to avoid a repeated screamer on the stream.

  5. Set size to 400×300 and place it in a corner
  1. Connect your account in the "Settings" section
